# 台灣交通動態系統

線上版：<https://ctyangthu.github.io/taiwan-live/>

把[台灣三大航空航班動態系統](https://ctyangthu.github.io/air-live/)與[台灣雙鐵動態系統](https://ctyangthu.github.io/rail-live/)合成一個網站，再加上**桃園機場捷運**與**高雄捷運**，並且能依航班的起飛時間，以「提早 2 小時到機場」為準，查出來得及的高鐵、臺鐵與捷運車次。

網站有兩個頁面，彼此可以互相跳轉：

| 頁面 | 內容 |
| --- | --- |
| `index.html` 地面交通・到機場 | 台灣地圖上的高鐵、臺鐵全車種、機場捷運、高雄捷運列車位置；四座機場的出發航班；搭機接駁、轉乘查詢、車站看板、時刻表 |
| `air.html` 航班世界地圖 | air-live 的世界地圖與航班動態，航班詳情多了「到機場交通」按鈕 |

## 搭機接駁

1. 在「搭機接駁」分頁選機場（桃園、松山、臺中、高雄）或搜尋航班號、目的地，也可以直接點地圖上的機場。
2. 點選航班後，系統算出**應抵達機場的時間**（起飛前 2 小時，可改成 1.5、2.5、3 小時）。
3. 選出發站（任一高鐵站、臺鐵站或捷運站），系統用當天的時刻表找出能在那個時間前抵達航廈的行程，由晚到早列出最多 5 個，第一個就是「最晚可搭」的班次，並標出到機場後距離起飛還有多久。
4. 當天首班車來不及（清晨航班）或航班在凌晨起飛時，改列前一晚的末班行程。

航班網址可以分享：`index.html#fly=BR6&ap=TPE&date=2026-11-13`。

### 到機場的方式

| 機場 | 接駁 | 資料 |
| --- | --- | --- |
| 桃園（第一、第二航廈） | 機場捷運 A12、A13 站，步行約 5 分 | 逐班時刻（直達車、普通車） |
| 高雄（小港） | 高雄捷運紅線 R4 站，步行約 6 分 | 逐班時刻 |
| 松山 | 台北捷運文湖線：台北車站約 28 分、南港約 30 分、臺鐵松山約 25 分 | **估計值**，未納入台北捷運時刻 |
| 臺中（清泉崗） | 市區公車：高鐵台中約 55 分、沙鹿約 25 分、臺中車站約 65 分 | **估計值**，公車班次較少，請另查時刻 |

捷運與雙鐵的轉乘點：台北車站（機捷 A1 ↔ 高鐵、臺鐵，約 12 分）、高鐵桃園（機捷 A18，約 8 分）、左營（高捷 R16 ↔ 高鐵、臺鐵新左營，約 8 分）、高雄車站（R11，約 6 分）、橋頭火車站（R23）、岡山車站（RK1）、美麗島（紅線 ↔ 橘線，約 4 分）。雙鐵之間的轉乘點同 rail-live。

桃園機場的航廈是推定的：長榮、立榮在第二航廈，星宇在第一航廈；華航依航線分屬兩個航廈（美洲、大洋洲與日本航線先假設在第二航廈），共掛航班以實際執飛的航空公司為準。畫面上可以自行切換航廈，請以機票或機場公告為準。

## 捷運資料

來源是交通部 [TDX 運輸資料流通服務](https://tdx.transportdata.tw/)的各站時刻表（`Rail/Metro/StationTimeTable`）。TDX 只公布「每一站往各終點的發車時刻」，沒有逐班列車，所以 `tools/build_metro.py` 把它重建成列車：從一個發車時刻出發，下一站取最接近預期行車時間的那個時刻，同一種停站方式的列車不會互相超車。終點站沒有發車時刻，到站時間用最後一站的時刻加上站間行車時間。

- 桃園機場捷運：平日、假日兩種班表；直達車（紫）與普通車（藍）。
- 高雄捷運紅線、橘線：週一至四、週五、週六、週日四種班表。
- 國定假日的班表未納入，一律依星期。
- 捷運列車沒有公開的車次編號，畫面上以「直達、普通、紅線、橘線」代替。

## 限制

- 列車與航班都依表定時刻推算，不含誤點、取消等即時資訊。
- 轉乘的步行與等候時間為估計值；松山與臺中機場的接駁是固定的估計時間。
- 未納入客運（國光、統聯等機場巴士）、台北捷運、臺中捷運、輕軌與計程車。
- 航班只有長榮、華航、星宇三家（含立榮、華信與共掛），班表為 2026/27 冬季（2026/10/25–2027/3/27）；其他航空公司的航班查不到。
- 「提早 2 小時」是一般建議，旺季、需要托運或退稅時請再提早。
- 其餘限制與兩個來源系統相同。本系統為非官方展示，實際行車與航班以各公司公告為準。

## 專案結構

```
src/app.html              地面交通頁（由 rail-live 的頁面擴充而來，資料以佔位字串嵌入）
src/air.html              航班地圖頁（tools/sync.py 從 air-live 複製，建置時加上導覽與連結）
data/                     高鐵、臺鐵資料與台灣地圖（從 rail-live 複製）
data/metro.json           機場捷運與高雄捷運的逐班列車（tools/build_metro.py 產生）
data/air/                 三家航空班表、機場、世界地圖、查核紀錄（從 air-live 複製）
raw/metro/                TDX 原始資料（不納入版本控制）
tools/sync.py             從 air-live、rail-live 複製資料
tools/fetch_metro.py      下載 TDX 捷運資料（6 次請求）
tools/build_metro.py      由各站時刻表重建逐班列車
tools/build.py            組出 dist/index.html、dist/air.html
tools/*tra*, *thsr*       與 rail-live 相同的臺鐵、高鐵資料工具
```

## 建置

```bash
python3 tools/build.py
```

來源系統有更新時先同步（air-live、rail-live 要放在這個專案的上一層目錄）：

```bash
python3 tools/sync.py
```

更新捷運時刻表（TDX 未登入時每天只能查詢少數幾次，請勿連續執行；有 TDX 帳號可設定 `TDX_TOKEN`）：

```bash
python3 tools/fetch_metro.py
```

```bash
python3 tools/build_metro.py
```

`src/app.html` 是這個專案自己的頁面，不會被同步覆蓋；rail-live 的頁面有修改時需要手動移植。

## 資料來源

- 航班：[air-live](https://github.com/ctyangthu/air-live)（長榮、華航、星宇官網時刻表與機場公告）。
- 高鐵、臺鐵：[rail-live](https://github.com/ctyangthu/rail-live)（台灣高鐵時刻表、臺鐵公司開放資料）。
- 捷運：交通部 TDX 運輸資料流通服務（桃園大眾捷運公司、高雄捷運公司）。
- 地圖：[taiwan-atlas](https://github.com/dkaoster/taiwan-atlas)（原始資料為內政部國土測繪中心開放資料）、[world-atlas](https://github.com/topojson/world-atlas)（Natural Earth）。
